Quick one before I head out, don't overthink it: CI only runs on Linux. Add `macos-latest` to the matrix in `.github/workflows/test.yml` so the tests run on both. Tests run with `python3 -m unittest discover -s tests -t .`. If you keep a change record for this, use the id `2026-11-08-ci-macos`. In this environment the repository cannot be branched or committed to: leave your changes in the working tree, do not try to work around that, and finish by writing the pull request description you would open.
